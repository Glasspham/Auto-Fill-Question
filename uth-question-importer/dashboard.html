UTH · QUESTION IMPORTER

Từ file câu hỏi đến ngân hàng Moodle.

Nhận Excel, CSV, Markdown hoặc TXT; kiểm tra nội dung, xem trước đáp án và nhập bằng phiên đăng nhập của bạn.

1. Chuẩn bị câu hỏi

Mỗi dòng một câu, 2–5 lựa chọn, một đáp án đúng. Nội dung là văn bản thuần, giữ xuống dòng.

Chưa chọn file · tối đa 5 MB / 1000 câu

2. Kết nối website

Mở tiện ích từ tab ngân hàng câu hỏi UTH.

Chọn một danh mục để áp dụng cho toàn bộ đợt, ưu tiên hơn danh mục trong file.

Xem trước 0 câu

Thứ tự điền vào form: đáp án đúng ở Choice 1, No numbering. Nếu bật xáo trộn, thứ tự hiển thị khi làm bài có thể thay đổi.

XML được dùng riêng qua mục “Nhập” của Moodle và không bảo toàn trạng thái draft/ready.

Quy ước file

Excel / CSV

Các cột: ma_cau (hoặc ID / Số ID), danh_muc, ten_cau (hoặc Name / Tên câu hỏi), noi_dung, A…E, dap_an_dung, diem, giai_thich, tron_dap_an, trang_thai, phan_hoi_A…E.

Markdown / TXT

Mỗi khối bắt đầu bằng Question 1., Câu 1. hoặc Ex 1.; lựa chọn A)–E); dòng Answer: B hoặc Đáp án: B. Ngay dưới đó có thể thêm Name / Tên câu hỏi và ID / Số ID; Explanation/Giải thích là tùy chọn.

Tool luôn chọn No numbering và chuyển đáp án đúng cùng phản hồi lên Choice 1.
